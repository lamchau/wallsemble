Changelog

Changes are listed newest first. Earlier entries describe development checkpoints, which were not all published.

0.7.8

Released on 2026-11-17.

Bug fixes

  • Keep invalid group-height feedback visible when opening a picture editor or switching views. Clear it when correcting the draft or changing the selected geometry.
  • Preserve range-error feedback when converting a pending height to another unit.

0.7.7

Released on 2026-11-17.

Bug fixes

  • Preserve redo when reapplying a preset or alignment, including fractional arrangements near wall insets. Keep existing coordinates when arithmetic adds only floating-point noise.
  • Report unchanged arrangements without claiming that pictures moved.

Refactoring

  • Share exact no-op detection between presets, randomization and selected-block positioning.

0.7.6

Released on 2026-11-17.

Bug fixes

  • Keep keyboard focus on a selected picture after Shift-click, Shift+Enter or Shift+Space changes the selection.
  • Nudge the remaining selection with arrow keys instead of unexpectedly reselecting a picture you just removed.

0.7.5

Released on 2026-11-17.

Bug fixes

  • Restore original picture positions and wire measurements when a drag is cancelled or pointer capture is lost.
  • Preserve redo after cancelled drags or moving a snapped arrangement back to its starting position.

0.7.4

Released on 2026-11-17.

Bug fixes

  • Keep empty picture-name drafts visible through other edits, theme changes and workspace switches.
  • Mark invalid picture and furniture names on their inputs. Clear the error state when corrected.

0.7.3

Released on 2026-11-17.

Bug fixes

  • Reject negative hook spacing before it reaches saved hardware measurements.
  • Keep invalid measurements visible until corrected before changing the hanging setup, wire method or hook count.

0.7.2

Released on 2026-11-17.

Bug fixes

  • Keep checked pictures selected when editing a picture in the selection.
  • Return keyboard focus to the control that opened the picture editor, including after measurement changes.
  • Keep unfinished measurements when using Center on wall or Use standard height. Preserve redo when these actions move nothing.

Refactoring

  • Share validation and history handling between the quick-placement controls. Remove the editor's selection-reset callback.

0.7.1

Released on 2026-11-17.

Enhancements

  • Start compositions with pictures and movement controls. Tuck layout and saved-group settings into optional sections.
  • Show which pictures each arrangement action affects. Use Select group and Randomize all labels.
  • Let the whole page scroll on phones instead of trapping controls in a second scrolling panel.

Bug fixes

  • Keep all selected pictures together when nudging a focused picture that is not being edited.
  • Preserve pending group-height edits through zoom and fit, without rounding measurements during unit changes.
  • Keep metric group heights readable on desktop and phones.
  • Preserve redo when clicking the active unit. Clear stale movement feedback and associate height errors with their input.

Refactoring

  • Give selection-position controls their own controller for drafts, validation and feedback. Keep measured geometry and history unchanged.

0.7.0

Released on 2026-11-17.

Enhancements

  • Add Select all and canvas-focused Cmd/Ctrl+A without changing groups or intercepting text-field shortcuts.
  • Position selected pictures as 1 block against wall insets or furniture, preserving internal spacing and hardware.
  • Set the selection's bounding-box center height in inches, fractions or centimeters. Reject positions that cannot fit without changing saved geometry or undo/redo.
  • Make Randomize place every picture in the current layout, regardless of selection. Keep other layout alternatives unchanged.

0.6.1

Released on 2026-11-17.

Bug fixes

  • Keep presets inside wall insets and above furniture clearance without shrinking pieces or gaps.
  • Leave the layout and undo history unchanged when a preset cannot fit.
  • Choose a fitting starter pattern when creating a composition.

Documentation

  • Add a changelog beside the version, rendered from Markdown at build time.
  • Move storage and privacy information to a separate Disclaimer page.
  • Clarify measurement instructions and remove routine save messages from the footer. Storage failures still appear in the planner.
