Disclaimer

Your data

No account is required. Wallsemble does not upload your measurements or arrangements. The public website is hosted on GitHub Pages; normal website requests are subject to GitHub's privacy practices.

Valid changes are saved in this browser on this device when browser storage is available. Plans are not synced across browsers or devices. Clearing site data can remove saved plans. Export JSON to keep a backup or share an arrangement. Anyone with the exported file can read its contents.

Undo and redo last only for the current session. Theme preferences are stored separately. Use Storage in the planner to clear Wallsemble data without removing other apps' data.

Before hanging

Wallsemble is a planning tool. Replace example values with your own measurements and check the result before drilling. Displayed measurements are rounded. JSON backups retain the underlying precision.

Wire lengths and hook positions are geometric calculations. The app does not predict wire stretch or certify wire strength, knots, mounting hardware, frames or wall capacity. Confirm the loaded wire position after fitting. A hook's bearing point is not necessarily the nail or screw position. Enter measured fastener offsets to calculate that mark.

Follow the hardware manufacturer's instructions and load ratings. For heavy or valuable pieces, or if you are unsure about the wall construction, seek advice from a qualified installer.

Layout limits

Presets keep measured sizes and gaps within wall insets and above furniture clearance. If a pattern cannot fit, nothing moves. Manual placement remains unrestricted and can produce warnings. Randomize places all pieces in the current layout, regardless of selection. It avoids overlaps but uses a bounded search, so it may not find every arrangement that could fit.

This app is under active development. Keep a JSON backup before trying a new version. See the changelog for changes.
